# 🔐 Sistema de Gestión de Usuarios - Full Stack

Sistema completo de autenticación de usuarios desarrollado con **Vue.js** (frontend) y **Flask** (backend) con base de datos **MySQL**.

## 🚀 Características

- ✅ **Autenticación segura** con bcrypt
- ✅ **API REST** con Flask y Blueprints
- ✅ **Frontend moderno** con Vue.js 3
- ✅ **Base de datos MySQL** 
- ✅ **Validaciones** en frontend y backend
- ✅ **Diseño responsive** 
- ✅ **Manejo de errores** completo

## 🛠️ Tecnologías Utilizadas

### Backend
- **Flask 3.0.3** - Framework web Python
- **MySQL** - Base de datos
- **bcrypt** - Hashing de contraseñas

### Frontend
- **Vue.js 3** - Framework JavaScript
- **Vite** - Build tool y dev server
- **Axios** - Cliente HTTP

## 🚀 Instalación y Uso

### 1. Backend
```bash
cd backend
pip install -r requirements.txt
python app.py
```

### 2. Frontend
```bash
cd frontend
npm install
npm run dev
```
